# Internal Notes (Not Public Docs)

This folder stores investigation notes and operational references that are useful for
maintainers but are not part of the public MkDocs site.

Guidelines:

- Keep ad-hoc investigations, experiments, and personal runbooks here.
- Do not link these files from `mkdocs.yml` navigation.
- Public-facing documentation should stay in `docs/`.
- Start new entries from `NOTE_TEMPLATE.md` for consistent structure.
- Use `TASK_TEMPLATE.md` for active handoffs and `POSTMORTEM_TEMPLATE.md` for incident follow-ups.
