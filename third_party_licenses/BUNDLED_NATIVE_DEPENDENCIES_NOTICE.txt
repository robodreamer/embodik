libraries from Pinocchio's dependency stack. A Linux auditwheel validation run

Release checklist:

1. Inspect each repaired wheel with `auditwheel show` on Linux or
   `delocate-listdeps` / `otool -L` on macOS.
2. Compare the bundled native libraries with this notice.
3. Add any newly bundled project and required license text before publishing.
4. Do not publish repaired wheels while this inventory is incomplete for the
   exact artifacts being uploaded.
