# EmbodiK Spot MJCF Asset Note

This directory vendors the public MuJoCo Menagerie Boston Dynamics Spot MJCF
asset as distributed through `robot_descriptions.spot_mj_description`. EmbodiK
uses this bundled copy by default for `examples/15_spot_locomanip_mjviser.py`
so pip-installed and copied examples do not need a first-run model download.

The source asset is BSD-3-Clause licensed and is derived from the public Spot
ROS description. See `README.md`, `CHANGELOG.md`, and `LICENSE` in this
directory for upstream details.
